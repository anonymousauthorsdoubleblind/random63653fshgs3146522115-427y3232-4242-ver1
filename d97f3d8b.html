Before you run

  • Hardware. Skala needs a GPU: an L4 (about 6 s per energy) or a T4 (about 8–10 s). Agent runs and all comparisons run on the CPU.
  • Gemini key. Agent runs need a Google Gemini API key stored as a Colab secret named GEMINI_API_KEY (a second key, GEMINI_API_KEY_2, is optional). The model identifier is gemini-3.8-flash. Without a key, a mock mode runs the pipeline but gives no real agent results.
  • Model weights. Skala-1.1 weights come from Hugging Face. The first call downloads them.
  • Threads. Set OMP_NUM_THREADS=1 when running agents in parallel. The notebooks do this.
  • Drive. Each notebook mounts Google Drive and writes to its own folder, listed in the table.
