# Review materials

Source code, results tables and interactive replays (static pages) for a computational study of reaction barriers. MIT licence.

## Publish on GitHub Pages

1. Create a public repository named `review-54680cbc1558` and push the contents of this folder to the repository root.
2. Settings → Pages → Deploy from a branch → `main`, folder `/ (root)`.
3. The site is then at `https://<user>.github.io/review-54680cbc1558/`.
4. Open `jfb80a026/config.js` and set `repo` to `<user>/review-54680cbc1558`. This activates the *Open in Colab* buttons. Commit and push.

Every page carries `<meta name="robots" content="noindex, nofollow">`. Leave the repository description, topics and website field empty.
